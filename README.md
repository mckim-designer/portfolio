# Mc Kim Modern Portfolio

Responsive portfolio website using HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and layout
- `style.css` — visual design, animations, and responsive layout
- `script.js` — project array, dynamic cards, filters, and mobile menu

## Add project images
Edit the `projects` array in `script.js`. Set an image path, for example `image: "images/citrus-theory.jpg"`. Place that image in an `images` folder next to the three main files. Blank `image` values show a typographic concept card instead. Categories are `branding`, `digital`, `video`, and `print`.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and this README to the root of your public repository. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
