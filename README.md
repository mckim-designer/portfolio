# Mc Kim — Graphic Design Portfolio

A responsive portfolio website for Mc Kim, freelance graphic designer in Nandi County, Kenya.

## Features
- Responsive layout with animated visual background and project concept samples
- Selectable Work, About, and Services navigation dropdowns
- Work dropdown filters project concepts by category
- About dropdown jumps to biography, education, and design focus
- Services dropdown jumps to relevant service entries
- Email and WhatsApp contact links

## Publish with GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, and this README to the root of a public GitHub repository. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.

The portfolio projects are illustrative concepts, not claimed client work. Replace them with original projects as available.
